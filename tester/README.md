# RecipeFinder — SKL 2

Nama: Rezad Dzaky Asshidiqie
Kelas: XI HSI Boarding School

## Fitur
Fetch API DummyJSON, search recipe, filter tag/cuisine/meal type, sorting, detail popup, favorite, LocalStorage, loading/error/empty state, dan responsive desktop/mobile.

## Alur
Fetch API → JSON → Array recipes → Render DOM → Search/Filter/Sort → Detail Popup → Favorite → LocalStorage.

## API
https://dummyjson.com/recipes

## Kendala
Menggabungkan search, filter, sorting, popup detail, dan favorite tanpa reload.

## Bagian yang masih dipelajari
Async/await, event delegation, dan cara kerja Fetch API.
